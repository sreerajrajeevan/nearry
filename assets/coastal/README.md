# Coastal artwork

`kochicoast.jpg` is original decorative scenery generated with the built-in image generation tool for this redesign, exported as an optimized 1600-pixel JPEG (about 126 KB). It does not represent a listed venue or a user's plan.

Generation prompt:

> Use case: photorealistic-natural. Asset type: decorative panoramic header background for Nearry, a nearby plans app set in Kochi, Kerala. Create a calm professional editorial photograph at blue hour: slender coconut palms silhouetted at the right, Kerala backwater waterfront, distant warm peach sunset clouds across a deep petrol-teal sky. Landscape ratio 3:1. Left half primarily dark teal sky and subtle water, low detail with strong negative space for white app branding, right half palms and warm horizon. Real natural photography, fine grain, not an illustration, no people, no text, no logos, no watermarks. Sophisticated deep teal #00454D with a very small peach sunset glow. Compose for heavy mobile cropping while retaining palms on right.

`demo-scenes.jpg` reuses the previously generated Nearry concept triptych: café coffee, an indoor badminton court, and a waterfront walk. `DemoPhoto` displays individual panels. Only explicit demo fixtures set `demoScene`; database mappers never return it. Uploaded photos always take priority. Real posts and offers without photos retain the existing honest activity-art fallback.

The approved logo geometry is unchanged. Its coral/teal colours, native splash and launcher images are produced by `assets/generate_icons.py`.
